# SCN-01 初見プレイ検証記録

Issue #15 の公開ゲート用。実参加者による記録が揃うまで、5人中4人の条件は未検証と扱う。

## 実施条件

- 初見の参加者5人を個別に募る。開発者が答えや操作を誘導しない。
- 同じリリース版、SCN-01入門、4年、学習案内ありを使う。各参加者のseed、Engine/Config版、端末、ブラウザを記録する。氏名などの個人情報は記録しない。
- 最初の四半期を通常の画面で進め、政策を確定するか無操作で進めるかは参加者が選ぶ。帰還後のホーム3行報告とレポートを自由に見る。
- 「いま最も大きく変わった指標と、その主な原因は何だと思いますか」とだけ尋ね、1分以内の本人の言葉を記録する。画面中の最大寄与と照らして、指標と原因の両方が概ね合えば成功。数値の暗記は不要。
- 続いて再読込と保存再開、危機時の明示的な再開、政策確定の二重タップ、オフラインでの1か月進行を確認する。破損、進行停止、二重確定を件数で記録する。

## 判定

- 最大変化要因の説明成功が5人中4人以上。
- 重大な保存消失、進行停止、二重確定はそれぞれ0件。
- 失敗や曖昧な回答は成功へ丸めず、再現seedと画面の根拠をIssue #15へ記録して修正・再試験する。
