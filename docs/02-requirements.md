MACRO NATION MVP 要件定義書
スマートフォン向け放置型国家運営シミュレーション
本書は企画版1.1を、設計、実装、テストに着手できるMVP要件へ整理したものです。経済モデルは現実を予測するものではなく、政策の時間差、副作用、政策間のトレードオフを一貫したルールで体験するためのゲームモデルです。
本書で確定する範囲
架空国家1国、6産業、主要9指標、5政策系統
導入1本と標準2本の合計3シナリオ、イベント12種
月次計算、四半期政策会議、最大8時間のオフライン進行
端末内保存、再現可能な乱数、因果ログ、受入テスト22件
文書の目的
本書は、企画書で示されたゲーム構想を、設計・実装・テストに着手できる要件へ落とし込むものである。
本作は現実経済の予測器ではない。架空国家を対象に、経済政策の方向、効果の時間差、副作用、政策間のトレードオフを一貫したルールで体験するゲームである。
本書では次の用語を使用する。
「必須」：MVP公開に必要な要件（P0）
「推奨」：MVPに含めるが、公開を止める条件にはしない要件（P1）
「将来」：MVP後に検討する要件（P2）
「調整値」：要件は固定するが、具体的な数値は設定ファイルで変更可能とするもの
プロダクト目標
目的
プレイヤーが、政策金利、税制、公共事業、関税、為替介入を組み合わせ、国民生活と持続的成長の両立を目指す放置型国家運営ゲームを提供する。
中心となる体験
1.  現在の経済状況を短時間で把握する。
2.  効果の時期と副作用を予想し、政策を最大3件決める。
3.  月次で経済が自動進行する。
4.  帰還時に「何が、なぜ変化したか」を確認する。
5.  過去の政策が遅れて効く状況で、次の政策を組み立てる。
MVP成功条件
異なる3つ以上の政策方針で標準シナリオを完了できる。
初見テスト参加者の70%以上が、帰還報告を見て最大の変化要因を1分以内に答えられる。
テスト参加者の30%以上が、別の政策を試すために2回目を開始する。
同じ初期条件、同じ操作、同じ乱数種なら、オンライン進行とオフライン一括進行の結果が一致する。
1,000回の8年自動実行と100回の30年自動実行で、NaN、無限大、進行不能、保存不能が発生しない。
対象ユーザー
主対象
経済ニュースには関心があるが、専門的なマクロ経済モデルには詳しくない高校生以上の利用者
国家運営、経営、戦略シミュレーションが好きな利用者
1回3～5分程度の短時間操作を、1日に1～2回行いたい利用者
補助対象
因果ログや詳細指標まで読みたい経済知識のある利用者
授業や自主学習のきっかけとして、政策のトレードオフを体験したい利用者

専門用語には一文の説明を表示する。
詳細な計算説明は任意に開く二層構造とする。

ゲーム内時間
1計算単位はゲーム内1か月とする。
標準速度は現実5分でゲーム内1か月とする。
現実15分でゲーム内1四半期、現実60分でゲーム内1年が進む。
シミュレーションは月末に1回実行する。
プレイヤーは任意に一時停止と再開ができる。一時停止中はオンライン、オフラインとも進行しない。
政策の編集画面と確認画面を開いている間は自動的に一時停止する。
シナリオ終了月を超えて進行しない。
導入シナリオの高速進行
SCN-01の最初の4四半期は、チュートリアル専用のステップ進行とする。
必須説明と政策選択を終えたあと、「次の四半期へ」を押すと3か月を即時計算して停止する。
4四半期終了後は標準速度または手動一時停止へ移行する。
チュートリアル中も通常と同じ計算エンジンを使用し、特別な結果補正は行わない。
政策会議
通常の政策会議は四半期の開始時に開ける。
1四半期に新規採用、変更、終了を合計3件まで確定できる。
1件の政策は、即時、次四半期、2四半期後、3四半期後のいずれかに予約できる。
予約は実施前であれば変更または取消可能だが、その四半期の政策枠を1件使用する。
実施済み政策の途中終了には、政策ごとの終了条件と政治コストを適用する。
3件を超える案は比較リストに置けるが、確定できない。
政策確定前の表示
全政策について、確定前に次を同一画面で表示する。
1.  主な期待効果
2.  効果が出始める時期
3.  効果が最も強くなる時期
4.  12か月後までの主要指標の予想レンジ
5.  主な副作用
6.  予算、政治資本、外貨準備、実施能力の消費
7.  継続期間と終了条件
8.  既存政策との主な相互作用
予想レンジは、基準、楽観、悲観の3条件を同じ計算エンジンで試算して作る。大量のモンテカルロ計算はMVPでは行わない。
緊急会議
危機停止が発生した場合、再開前に緊急会議を表示する。
緊急会議では最大3件の即時政策を実施できる。
緊急政策は通常の四半期枠を消費しない代わりに、政治資本コストを通常の1.25倍とする。
「政策を行わず再開」も選択可能とする。
緊急会議を閉じただけではシミュレーションを再開しない。
勝敗と終了
シナリオ最終月まで国家が存続すれば完了とする。
完了時は「暮らし」「成長」「安定」「持続性」「信頼」の5軸を0～100点で評価する。
総合基礎点は次の加重平均とする。
総合基礎点 = 暮らし×0.30 + 成長×0.25 + 安定×0.20 + 持続性×0.15 + 信頼×0.10
単独指標の最大化を防ぐため、総合点には次の上限を適用する。
総合点上限 = 60 + 最低評価軸×0.40
最終総合点は、総合基礎点と総合点上限の小さい方とする。
評価はS（90以上）、A（80以上）、B（70以上）、C（60以上）、D（60未満）、F（国家運営失敗）とする。
最終失敗条件
失敗条件と閾値はシナリオ設定で変更できるようにし、MVPの初期値は次のとおりとする。
失敗直前には、少なくとも1段階の警戒状態と緊急会議を発生させる。完全な不意打ちで即失敗させない。

1か月の更新順序
更新順序は固定し、次の順で処理する。
1.  当月発動する予約政策を有効化し、予算、政治資本、外貨準備、実施能力を処理する。
2.  海外成長、資源価格、海外金利、相手国状態を更新する。
3.  既存政策の効果キューとイベント効果を当月分だけ取り出す。
4.  家計消費、企業投資、政府支出、輸出入を更新する。
5.  実質GDP、潜在GDP、需給ギャップ、6産業の生産を更新する。
6.  CPI、輸入物価、賃金、失業を更新する。
7.  税収、歳出、利払い、財政収支、政府債務を更新する。
8.  為替、資本移動、外貨準備、市場信認を更新する。
9.  家計実質所得、格差、支持、政策信頼、政治資本を更新する。
10.  イベント、危機、失敗、シナリオ完了、実績を判定する。
11.  因果ログ、月次スナップショット、乱数状態を保存する。
更新順序は保存データのengineVersionに紐付け、途中のバージョン変更で結果を変えない。
基本関係式
実装では以下の関係を満たす。係数は設定ファイルに置き、コードへ直書きしない。
消費成長 = 基礎傾向
         + 実質所得効果
         - 実質金利効果
         - 失業不安効果
         - 物価不安効果
         + 税・給付効果
         + 誤差

投資成長 = 基礎傾向
         + 需要見通し効果
         + 生産性効果
         - 実質金利効果
         - 不確実性効果
         + 法人税効果
         + 誤差

実質GDP = 消費 + 投資 + 政府支出 + 輸出 - 輸入

物価変化 = 需要超過効果
         + 輸入物価効果
         + 期待インフレ効果
         + 供給制約効果
         + 誤差

失業変化 = 産出量不足の遅延効果
         + 産業再編効果
         - 雇用政策効果
         + 誤差

為替変化 = 金利差効果
         + 経常収支効果
         + 信頼効果
         + 資本移動効果
         + 介入効果
         + 誤差

政府債務 = 前月債務 + 基礎的赤字 + 利払い

政策信頼変化 = 物価安定効果
               + 雇用効果
               + 政策一貫性効果
               + 公約達成効果
               + 制度尊重効果
               - 危機・場当たり変更の効果
数値安定性
各状態値には経済上・ゲーム上の上下限を設定する。
上下限へ達した場合は、単純な切り捨てだけでなく、開発ログへ違反前の値と原因を残す。
0除算、NaN、Infinityを検出したtickは確定せず、直前保存へ復旧する。
人口、GDP、価格指数、準備、債務など、定義上負にならない値は0未満にしない。
極端な税率、関税率、金利をUIと設定検証の両方で制限する。

乱数
Math.random()は使用しない。
JavaScriptの整数演算で再現できる固定アルゴリズムを採用し、アルゴリズム版を保存する。
初期seed、現在の乱数状態、使用回数を保存する。
イベント、外部環境、誤差項は用途別の乱数系列へ分離し、一方の機能追加で他方の結果が不必要に変わらないようにする。
同一エンジン版、同一設定版、同一seed、同一操作列では完全一致を必須とする。

テスト要件
単体テスト
政策なしの基準ケースが8年完走する。
同じ入力と乱数状態に対するtickが同じ出力を返す。
利上げ幅を大きくすると、平均的に物価と需要が弱くなる。
公共投資の短期需要効果と長期供給効果が異なる月に発現する。
為替介入のみを反復すると外貨準備が減り、基礎条件が悪い場合に効果が減衰する。
関税が対象産業を保護する一方、輸入価格または川下コストを上げる。
税変更が税収、需要、格差へ異なる経路で作用する。
寄与ログの合計が指標変化と許容誤差以内で一致する。
設定上の上下限違反、不正な効果期間、不正確率を検出する。
結合テスト
政策予約から発動、効果、終了、レポート表示まで一致する。
イベント兆候から発生、選択、遅延効果、ログまで一致する。
保存、終了、再開後もタイマー、乱数、効果キューが一致する。
逐次96tickとオフライン一括96tickが一致する。
バージョン移行後も既存保存を読み込める。
E2Eと受入テスト
バランス調整要件
調整順序
1.  政策なしの基準ケースを1,000回実行し、自然変動と破綻率を確認する。
2.  各政策を単独で最小・標準・最大に動かし、方向、上限、ラグを確認する。
3.  政策を組み合わせ、相殺、増幅、副作用の連鎖を確認する。
4.  代表戦略を自動実行し、固定手順が支配的にならないよう調整する。
5.  少人数テストで理解度、再挑戦意向、操作時間を確認する。
6.  限定公開版の設定版を固定し、以後の修正は版番号を更新する。
代表戦略
少なくとも次の方針を自動実行・手動検証する。
